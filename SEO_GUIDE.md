## SEO Basics

### What is SEO?
Search Engine Optimization (SEO) is the practice of optimizing your website to rank higher in search engine results pages (SERPs) for relevant keywords.

### Why SEO Matters for Software Development Agencies
- **Increased Visibility**: Higher rankings = more potential clients seeing your services
- **Cost-Effective**: Organic traffic is free compared to paid advertising
- **Credibility**: Top rankings build trust and authority
- **Targeted Traffic**: People searching for software development services are high-intent prospects

## On-Page SEO

### Title Tags
- **Format**: Primary Keyword | Secondary Keyword | Brand Name
- **Length**: 50-60 characters
- **Examples**:
  - "Custom Software Development | Web & Mobile Apps | Nexus"
  - "React Development Services | Full-Stack Solutions | Nexus"

### Meta Descriptions
- **Length**: 150-160 characters
- **Include**: Primary keyword, value proposition, call-to-action
- **Example**: "Transform your ideas into powerful software solutions. Nexus builds custom web apps, mobile apps, and APIs. Get your free quote today!"

### Header Structure
```html
H1: One per page, include primary keyword
H2: Section headers with secondary keywords
H3: Subsection headers
H4-H6: Supporting content hierarchy
```

### URL Structure
- **Good**: `/custom-web-development-services`
- **Bad**: `/page1?id=123&category=dev`

### Internal Linking
- Link related pages together
- Use descriptive anchor text
- Create content hubs (pillar pages)

## Technical SEO

### Core Web Vitals
1. **Largest Contentful Paint (LCP)**: < 2.5 seconds
2. **First Input Delay (FID)**: < 100 milliseconds
3. **Cumulative Layout Shift (CLS)**: < 0.1

### Mobile Optimization
- Responsive design
- Fast loading on mobile
- Touch-friendly navigation
- Readable text without zooming

### Site Speed Optimization
- Optimize images (WebP format)
- Minify CSS/JS
- Use CDN
- Enable compression
- Leverage browser caching

### Schema Markup
```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Nexus Software Development",
  "description": "Custom software development agency",
  "url": "https://nexus.com",
  "telephone": "+1-555-0123",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "123 Tech Street",
    "addressLocality": "San Francisco",
    "addressRegion": "CA",
    "postalCode": "94105"
  }
}
```

## Link Building

### Strategy for Software Agencies
1. **Guest Posting**: Write for tech blogs and industry publications
2. **Resource Pages**: Get listed on "best software companies" lists
3. **Partnerships**: Link exchanges with complementary businesses
4. **Client Testimonials**: Links from client websites
5. **Open Source**: Contribute to projects, get attribution links

### Quality Link Sources
- Industry publications (TechCrunch, Mashable)
- Developer communities (Dev.to, Stack Overflow)
- Business directories (Clutch, G2)
- University resources
- Government sites (.gov, .edu)

## Common Mistakes

### What NOT to Do
1. **Keyword Stuffing**: Don't overuse keywords unnaturally
2. **Buying Low-Quality Links**: Can result in penalties
3. **Duplicate Content**: Hurts rankings across all pages
4. **Ignoring Mobile**: Mobile-first indexing is crucial
5. **Slow Loading**: Users and search engines hate slow sites

### Red Flags to Avoid
- Guaranteed #1 rankings
- Cheap SEO services
- Link farms or paid link schemes
- Cloaking or hidden text
- Doorway pages
